# Capsl

Capsl ist eine einfache, lokale Supplement-Tracker-App.

Die App ist bewusst clean gehalten: keine Anmeldung, keine Cloud, keine externen Abhängigkeiten. Daten werden lokal im Browser gespeichert.

## Features

- Tagesübersicht für Supplements
- Supplements hinzufügen, bearbeiten, pausieren und löschen
- Einnahmen als erledigt abhaken
- Fortschritt und Tagesabschluss
- Vorrat und Reichweite tracken
- Vorrat auffüllen
- 7-Tage-Historie
- Daten exportieren und importieren
- Lokale Speicherung per `localStorage`
- Responsive Design für Desktop und Mobile

## Dateien


## Lokal starten

Im Projektordner:

```bash
python3 -m http.server 8000
```

Dann im Browser öffnen:

```text
http://localhost:8000/
```
