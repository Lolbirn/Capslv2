Datenschutzerklärung

Keine Datenerhebung durch die App

Capsl speichert alle Angaben (Supplements, Einnahmen, Vorrat) ausschließlich lokal im Browser deines Geräts (localStorage). Es findet keine Übertragung an einen Server statt, es gibt keine Konten, kein Tracking und keine Cookies.

Diese Seite wird über GitHub Pages (GitHub Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA) bereitgestellt. Beim Aufruf verarbeitet GitHub automatisch technische Zugriffsdaten (u. a. IP-Adresse) in Server-Logs, wie bei jedem Website-Aufruf üblich. Näheres dazu in der Datenschutzerklärung von GitHub.

Datenexport

Über die Backup-Funktion kannst du deine Daten jederzeit als Datei exportieren, löschen oder auf ein anderes Gerät übertragen. Ein Löschen der App bzw. der Website-Daten im Browser entfernt alle gespeicherten Angaben vollständig.
