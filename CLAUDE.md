# Claude Handoff: Capsl

Dieses Projekt ist eine statische Supplement-Tracker-App namens **Capsl**.

## Kontext

Der Nutzer baut eine erste einfache App und bevorzugt eine cleane, moderne, hochwertige Optik. Wichtig ist, dass die App übersichtlich bleibt und nicht mit zu vielen Features überladen wird.

## Produktidee

Capsl hilft dabei, tägliche Supplements zu verwalten:

- Supplements eintragen
- Einnahme täglich abhaken
- Vorrat und Reichweite verfolgen
- Daten lokal speichern
- Backup exportieren/importieren

Keine Anmeldung, keine Cloud, keine API.

## Technischer Stand

Statische Web-App:

- `index.html`
- `styles.css`
- `app.js`

Keine Build-Tools und keine externen Libraries.

Datenhaltung:

- `localStorage`
- Keys: `capsl-supplements-v1`, `capsl-checks-v1`

## Designrichtung

- Premium Supplement / Health Utility
- Clean, ruhig, modern
- Charcoal, Creme, Gold, Sage
- Keine Marketing-Landingpage
- Die App selbst soll direkt im ersten Screen nutzbar sein

## Wichtig für weitere Arbeit

- Neue Features nur hinzufügen, wenn sie die Übersicht nicht verschlechtern.
- Bestehende Einfachheit erhalten.
- Mobile Nutzung ist wahrscheinlich sehr wichtig.
- Deutsche UI beibehalten; Englisch/weitere Sprachen später vorbereiten.
